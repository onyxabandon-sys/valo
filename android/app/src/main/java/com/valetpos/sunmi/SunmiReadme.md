# SUNMI V2 Pro printer bridge

`SunmiBridgeModule` binds the official SUNMI printer service, validates the
receipt payload, checks printer readiness, and prints through a transaction
buffer. A print succeeds only after the SDK callback confirms it.

The native confirmation deadline is 10 seconds. A timeout is intentionally
reported as ambiguous: the operator must inspect the paper before retrying so
that a delayed printer acknowledgement does not cause an accidental duplicate.

Barcode scanning is outside the current vehicle-entry flow and fails closed as
unsupported. The printed barcode is generated by the built-in printer from the
receipt number.
